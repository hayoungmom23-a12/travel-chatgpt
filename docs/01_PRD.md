# 여행 조건 기반 일자별 여행 계획 도구 PRD

## 문제

여행자는 제한된 시간과 예산 안에서 자신의 취향에 맞는 일정을 짜기 어렵고, 검색 결과를 비교·정리하는 데 많은 시간을 쓴다. 특히 일자별 동선, 비용, 준비물, 날씨 변수까지 한 번에 고려하기 어렵다. 본 서비스는 몇 가지 여행 조건만 입력하면 실행 가능한 초안 일정을 빠르게 제안해 계획 시작의 부담을 낮춘다.

## 대상 사용자

- 국내·해외 자유여행을 처음 준비하거나, 짧은 시간 안에 여행 계획 초안이 필요한 개인 및 소규모 그룹
- 여행 취향·동행자 관계·피하고 싶은 요소를 반영한 맞춤형 일정을 원하는 사용자

## 사용자 시나리오

사용자는 여행지, 일정, 인원, 예산, 여행 스타일, 함께 가는 사람의 관계, 피하고 싶은 것을 입력한다. 서비스는 입력 조건의 충돌이나 부족한 정보를 자연어로 보완해 해석한 뒤, 날짜별 추천 코스와 예산 배분을 제시한다. 사용자는 우천 시 대안을 확인하고 준비물 체크리스트를 활용해 여행 계획을 확정하거나 추가 조사한다.

## 입력·처리·출력

| 구분 | 내용 |
| --- | --- |
| 입력 | 여행지, 일정(출발·도착일 또는 일수), 인원, 총 예산, 여행 스타일, 함께 가는 사람의 관계, 피하고 싶은 것 |
| 처리 | 일정과 이동 부담을 고려해 일자별 활동을 구성하고, 여행 스타일·동행자 관계·제외 조건을 반영한다. 총 예산을 교통·숙소·식비·활동·예비비 등으로 추정 배분하며, 비 예보 또는 우천 상황을 가정한 실내·대체 활동을 함께 제안한다. 가격·운영시간 등 실시간 검증이 필요한 정보는 추정 또는 확인 필요 항목으로 명시한다. |
| 출력 | ① 일자별 코스(시간대별 활동, 식사, 이동·휴식 흐름) ② 예상 예산표(항목별·인당/총액 구분) ③ 준비물 체크리스트 ④ 우천 시 대안. 결과에는 가정, 추정치, 사용 전 확인이 필요한 항목을 함께 표시한다. |

## 범위

- 한 번의 조건 입력으로 여행 계획 초안을 생성하고 화면에서 읽기 쉽게 제공한다.
- 일정의 각 날짜에 핵심 활동, 식사 제안, 이동·휴식 여유, 우천 대안을 포함한다.
- 예산은 사용자가 입력한 총액을 기준으로 항목별 예상 범위를 제시하며, 인원 기준을 명확히 표시한다.
- 생성된 일자별 코스, 예상 예산표, 준비물 체크리스트, 우천 시 대안을 결과 화면에서 직접 수정할 수 있게 한다. 수정한 예산은 합계와 잔여 예산을 다시 계산하고, 모든 가격·운영 관련 값은 추정 또는 사용자 수정값으로 표시한다.
- 현지 가격·운영시간·휴무·예약 필요 여부는 보장하지 않으며, 사용자에게 공식 채널 확인을 안내한다.
- 결과의 장소·업체 정보를 사용자가 확인할 수 있도록 외부 지도 서비스로 연결한다. 실시간 길찾기와 위치 추적은 제공하지 않는다.
- 로그인 없이 현재 기기·브라우저에서 생성한 일정을 보관하고 다시 열람할 수 있게 한다.
- 생성한 일정을 사용자가 선택한 공유 수단으로 전달할 수 있게 한다.

## 제외 범위

- 숙소·교통·관광·식당의 예약 및 결제
- 실시간 가격, 좌석·재고, 운영시간, 휴무 정보의 조회·보장
- 실시간 길찾기, 위치 추적
- 로그인 및 계정 관리

## 성공 기준

- 계획 생성 완료 사용자의 80% 이상이 입력 후 2분 이내에 결과 화면에 도달한다.
- 결과 화면의 90% 이상에 일자별 코스, 예상 예산표, 준비물 체크리스트, 우천 시 대안 네 요소가 모두 포함된다.
- 사용자 설문에서 70% 이상이 “내 조건과 대체로 맞는 여행 계획 초안”이라고 평가한다.
- 가격·운영시간 관련 문구가 추정 또는 확인 필요로 표시되지 않은 사례를 0건으로 유지한다.
