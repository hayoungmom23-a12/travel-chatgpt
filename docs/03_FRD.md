# 여행 조건 기반 일자별 여행 계획 도구 FRD

| --- | --- | --- | --- |

| F-02 | 여행지 빠른 선택 (PRD에 없음) | 입력 | 시안의 추천 여행지 칩을 눌러 여행지를 빠르게 채운다. |
| F-03 | 일정 입력 | 입력 | 출발일과 도착일을 입력해 여행 일수·박수를 산출한다. |

| F-10 | 여행 요약 및 이동 피로도 표시 (이동 피로도는 PRD에 없음) | 결과 | 생성된 일정의 핵심 조건·예산·이동 부담을 요약한다. |
| F-11 | 일자별 코스 조회 | 결과 | 선택한 날짜의 시간대별 코스와 이동·휴식 흐름을 보여 준다. |

| F-19 | 일정 공유 | 결과 | 생성된 계획 요약을 사용자가 선택한 공유 수단으로 전달한다. |

## 2) 입력 항목 표

| 항목명 | 필수 여부 | 형식 | 검증 규칙 | 기본값 |
| --- | --- | --- | --- | --- |
| 여행지 | 필수 | 텍스트, 도시 또는 지역명 | 공백 제거 후 1자 이상 입력해야 하며, 국가·도시·권역처럼 식별 가능한 장소명이어야 한다. 외부 지도·실시간 정보로 존재 여부를 보장하지 않는다. | 없음. 시안은 `제주도 서귀포 및 동부`를 예시로 표시한다. |

| 총 예산 | 필수 | 원화 정수, 쉼표 허용 | 쉼표·원화 기호를 제거한 값이 1원 이상인 정수여야 한다. 음수, 0, 문자만 입력된 값은 허용하지 않는다. | `1,200,000원` |
| 여행 스타일 | 선택 | 다중 선택: 자연·힐링, 감성 카페·미식, 액티비티, 문화·역사 | 중복 선택은 허용하지 않는다. 선택하지 않으면 균형형 기본 코스를 사용한다. 별도의 음식 취향 입력은 제공하지 않는다. | `자연·힐링`, `감성 카페·미식` |
| 피하고 싶은 것 | 선택 | 태그 목록 및 자유 텍스트 | 빈 값은 허용한다. 태그는 중복 없이 저장하며, 삭제 버튼으로 개별 제거할 수 있다. 자유 입력은 제외 조건으로 태그화해 생성 요청에 포함한다. | `긴 도보 이동(1시간 이상)`, `대기시간 40분 이상 맛집` |

## 3) 기능 상세

### F-01. 여행지 입력

- 사용자 행동: 여행지 입력란에 국내·해외의 도시, 지역 또는 여행 권역을 입력하고, 필요하면 지우기 버튼으로 값을 비운다.
- 입력값: 여행지 텍스트.
- 처리 규칙: 앞뒤 공백을 제거한 값을 계획 조건에 저장한다. 장소의 실시간 운영 정보, 가격 또는 지도 경로를 조회하지 않는다.
- 출력값: 입력란의 여행지와 이후 생성 화면에 표시할 여행지 조건.
- 오류 상태: 값이 비어 있거나 장소를 식별할 수 없는 형태이면 “여행지를 도시 또는 지역명으로 입력해주세요.”를 입력란 아래에 표시한다.
- 완료 조건: 유효한 여행지 값이 입력 검증을 통과한다.

### F-02. 여행지 빠른 선택 (PRD에 없음)

- 사용자 행동: 시안에 제시된 추천 여행지 칩(예: 제주, 강릉·속초, 후쿠오카)을 선택한다.
- 입력값: 선택한 추천 여행지명.
- 처리 규칙: 선택값으로 기존 여행지 입력값을 교체한다. 칩은 입력 편의 기능일 뿐, 추천 지역의 실시간 인기·가격 정보를 의미하지 않는다.
- 출력값: 갱신된 여행지 입력값.
- 오류 상태: 별도 오류 상태는 없다. 선택값이 비어 있으면 F-01의 검증을 적용한다.
- 완료 조건: 선택한 여행지명이 여행지 입력란에 반영된다.

### F-03. 일정 입력

- 사용자 행동: 출발일과 도착일을 입력하거나 선택한다.
- 입력값: 출발일, 도착일.
- 처리 규칙: 두 날짜의 유효성을 확인하고 `도착일 - 출발일 + 1`로 여행 일수, `도착일 - 출발일`로 박수를 계산한다. 도착일이 출발일보다 앞서면 생성 요청을 막는다.
- 출력값: 입력 화면의 여행 기간 표기와 결과 요약의 날짜·N박 N일 정보.
- 오류 상태: 날짜 형식이 올바르지 않으면 “날짜를 다시 입력해주세요.”, 도착일이 앞서면 “도착일은 출발일 이후여야 합니다.”를 표시한다.
- 완료 조건: 유효한 출발일·도착일이 입력되고 1일 이상의 여행 기간이 계산된다.

### F-04. 인원 및 동행자 관계 입력

- 사용자 행동: 인원 선택값과 함께 가는 사람의 관계를 각각 선택한다.
- 입력값: 인원, 동행자 관계.
- 처리 규칙: 인원과 관계를 함께 계획 생성 조건으로 저장한다. 1명일 때는 혼자 여행 관계로 맞추고, 2명 이상일 때 혼자 여행 관계가 선택되면 관계 재선택을 요구한다.
- 출력값: 입력 조건과 결과 요약의 `인원·관계` 표기, 코스 난이도·휴식 비중에 사용할 조건.
- 오류 상태: 둘 중 하나가 없거나 인원과 관계가 맞지 않으면 “인원과 동행자 관계를 함께 선택해주세요.”를 표시한다.
- 완료 조건: 유효한 인원과 그에 맞는 관계가 선택된다.

### F-05. 총 예산 입력

- 사용자 행동: 총예산을 원화 기준으로 입력한다.
- 입력값: 총예산 금액.
- 처리 규칙: 숫자·쉼표·원화 기호를 정규화해 원화 정수로 변환한다. 입력 인원이 단일값이면 1인 참고 금액을 `총예산 ÷ 인원`으로 계산하고, 인원이 범위이면 1인 참고 범위를 표시한다.
- 출력값: 총예산과 입력 화면의 1인 참고 금액.
- 오류 상태: 0 이하, 음수 또는 숫자로 변환할 수 없는 값이면 “총예산을 1원 이상의 숫자로 입력해주세요.”를 표시한다.
- 완료 조건: 양의 원화 정수가 저장되고 1인 참고 금액 또는 범위가 표시된다.

### F-06. 여행 스타일 선택

- 사용자 행동: 하나 이상의 스타일을 체크하거나 해제한다.
- 입력값: 선택된 스타일 목록.
- 처리 규칙: 다중 선택을 허용하고, 중복은 저장하지 않는다. 선택값이 없으면 균형형 기본 코스를 적용한다. `감성 카페·미식`은 여행 스타일 선택지이며, 음식 취향을 별도로 수집하는 기능은 아니다.
- 출력값: 선택된 스타일의 시각적 상태와 생성 요청에 포함될 스타일 목록.
- 오류 상태: 선택 항목은 선택사항이므로 별도 오류 상태는 없다.
- 완료 조건: 사용자가 원하는 스타일 조합을 확정하거나, 미선택 상태로 기본 코스 적용을 허용한다.

### F-07. 피하고 싶은 것 관리

- 사용자 행동: 제외 조건을 직접 입력해 추가하고, 기존 태그의 삭제 버튼을 눌러 제거한다.
- 입력값: 자유 텍스트와 제외 조건 태그 목록.
- 처리 규칙: 자유 텍스트는 태그로 변환해 목록에 추가하며, 공백 태그와 중복 태그는 저장하지 않는다. 모든 태그는 생성 시 활동·식사·이동 후보를 제외 또는 완화하는 조건으로 전달한다.
- 출력값: 추가·삭제된 제외 조건 태그 목록.
- 오류 상태: 중복 또는 빈 값을 추가하려 하면 목록을 변경하지 않고 “이미 추가했거나 비어 있는 조건입니다.”를 표시한다.
- 완료 조건: 사용자가 제외할 조건 목록을 확정하거나, 빈 목록으로 진행한다.

### F-08. 입력 검증 및 계획 생성 요청

- 사용자 행동: `여행 계획 만들기`를 선택한다.
- 입력값: F-01~F-07에서 확정한 전체 여행 조건.
- 처리 규칙: 필수값과 형식을 한 번에 검증한다. 오류가 있으면 첫 오류 항목으로 포커스를 이동하고 생성하지 않는다. 검증을 통과하면 조건 스냅샷을 만들어 F-09로 전환한다.
- 출력값: 검증 성공 시 처리 중 화면, 실패 시 항목별 오류 메시지.
- 오류 상태: 필수 여행지·일정·인원·동행자 관계·예산 중 누락 또는 형식 오류가 있으면 해당 입력란에 오류를 표시한다.
- 완료 조건: 유효한 전체 조건이 생성 요청으로 전달되거나, 모든 오류가 사용자에게 명확히 표시된다.

### F-09. AI 계획 생성 진행 표시

- 사용자 행동: 생성 요청 후 진행 상태를 확인한다.
- 입력값: 검증된 여행 조건 스냅샷과 계획 생성 작업 상태.
- 처리 규칙: `조건·동행자 편의성 검토 → 일자별 동선·활동 구성 → 예산 배분 → 준비물·우천 대안 구성` 순서의 상태를 표시한다. 실제 완료 신호를 받기 전에는 완료로 표시하지 않으며, 실시간 가격·운영시간을 조회하거나 보장하지 않는다.
- 출력값: 처리 중 안내, 반영 중인 주요 조건, 단계별 진행 상태.
- 오류 상태: 조건 충돌이면 F-20, 생성 작업 실패·시간 초과면 F-21로 전환한다.
- 완료 조건: 필수 결과 데이터가 완성되어 F-10~F-15를 표시하거나, 오류 화면으로 전환된다.

### F-10. 여행 요약 및 이동 피로도 표시 (이동 피로도는 PRD에 없음)

- 사용자 행동: 생성 완료된 결과 상단의 여행 요약을 확인한다.
- 입력값: 생성된 여행지, 일정, 인원·관계, 예산 배분 결과, 코스별 이동량.
- 처리 규칙: 여행지·날짜·박수·인원·관계·총예산·1인 참고 금액을 입력값과 일치하게 표시한다. 시안의 이동 피로도는 일별 활동 수, 연속 이동, 휴식 간격을 기준으로 `낮음/보통/높음`으로 계산한 참고 지표이며, 실제 교통 상황을 반영하거나 보장하지 않는다.
- 출력값: 생성 완료 상태, 여행 요약, 총예산·1인 참고 금액, 이동 피로도.
- 오류 상태: 요약에 필요한 값이 없으면 해당 항목을 `정보 없음`으로 표시하고 F-16으로 조건 수정을 유도한다.
- 완료 조건: 사용자에게 생성 결과의 핵심 조건과 참고 지표가 한 화면에 표시된다.

### F-11. 일자별 코스 조회

- 사용자 행동: 일자 탭을 선택해 각 날짜의 코스를 확인한다.
- 입력값: 선택한 여행 일자와 생성된 일자별 활동 목록.
- 처리 규칙: 선택한 날짜의 시간대별 핵심 활동, 식사 제안, 이동, 휴식 여유를 보여 주며 F-06의 스타일과 F-07의 제외 조건을 반영한다. 총 일정의 모든 날짜에 코스가 존재해야 하며, 장소의 영업 여부·운영시간은 확정 사실처럼 표시하지 않는다.
- 출력값: 선택 일자의 타임라인형 코스와 활동 유형·이동 또는 휴식 안내.
- 오류 상태: 특정 날짜의 코스 생성에 실패하면 “해당 일자의 코스를 만들지 못했습니다. 조건을 수정해 다시 만들어주세요.”를 표시한다.
- 완료 조건: 사용자가 모든 여행 일자의 코스를 조회할 수 있다.

### F-12. 예상 예산표 조회

- 사용자 행동: 결과의 예산표를 확인한다.
- 입력값: 총예산, 인원, 생성된 숙소·교통·식비·활동·예비비 배분값.
- 처리 규칙: 항목별 총액, 1인 환산액(또는 인원 범위에 따른 참고 범위), 합계, 남은 예산을 계산한다. 모든 금액은 `추정치`로 표시하고, 항공료처럼 산정에서 제외한 항목은 명시한다. 실시간 가격 또는 예약 가능 가격처럼 보이는 표현은 사용하지 않는다.
- 출력값: 예상 예산 배분표, 추정치 배지, 총액·1인 환산액·잔여 예산, 제외 항목 안내.
- 오류 상태: 특정 항목을 추정할 수 없으면 해당 항목을 `추정 불가`로 표시하고 총액 계산에서 제외한 사실을 함께 안내한다.
- 완료 조건: 사용자가 총예산 대비 배분 내역과 금액의 비보장 성격을 확인할 수 있다.

### F-13. 준비물 체크리스트 확인·체크 (체크 상태는 PRD에 없음)

- 사용자 행동: 준비물 목록을 확인하고 항목별 체크박스를 선택 또는 해제한다.
- 입력값: 여행지·기간·스타일·동행자 관계에서 생성된 준비물과 각 항목의 체크 상태.
- 처리 규칙: 기본 준비물과 우천·동행자 조건에 따른 준비물을 제시한다. 체크된 항목은 완료 스타일로 표시한다. 체크 상태는 F-18로 보관한 일정에만 현재 기기에서 함께 저장한다.
- 출력값: 준비물 체크리스트와 각 항목의 완료 여부.
- 오류 상태: 체크 상태 저장에 실패하면 체크는 현재 화면에 유지하고 “이 기기에는 체크 상태를 보관할 수 없습니다.”를 표시한다.
- 완료 조건: 준비물 목록이 표시되고 사용자가 항목의 준비 완료 여부를 확인할 수 있다.

### F-14. 우천 시 대안 조회

- 사용자 행동: 결과의 `우천 시 실내 대안(Plan B)` 영역을 확인한다.
- 입력값: 일자별 야외 활동, 여행 스타일, 제외 조건, 예산 배분.
- 처리 규칙: 각 야외 활동에 대해 목적과 이동 부담이 비슷한 실내 대안을 매핑한다. 이 기능은 실시간 날씨·강수 예보를 조회하지 않으므로 `비 예보` 여부를 판단하거나 보장하지 않으며, 우천 발생 시 참고할 대안으로만 표시한다.
- 출력값: `기존 야외 활동 → 실내 대안` 형식의 대체 코스와 확인 필요 안내.
- 오류 상태: 동등한 실내 대안을 찾지 못하면 “이 활동의 실내 대안은 확인이 필요합니다.”를 표시한다.
- 완료 조건: 결과에 우천 시 참고할 수 있는 대안 목록이 표시된다.

### F-15. 추정치 및 공식 채널 확인 안내

- 사용자 행동: 결과 하단의 확인 안내를 읽는다.
- 입력값: 예산표와 코스에 포함된 금액·운영 관련 추정 정보.
- 처리 규칙: 가격, 운영시간, 휴무, 예약 필요 여부가 확인되지 않은 정보임을 명시하고 공식 채널 확인을 안내한다. 이 기능은 가격·운영시간을 조회·보장하지 않는다.
- 출력값: `추정치`, `공식 채널 확인 필요` 등의 경고 문구와 확인 안내.
- 오류 상태: 안내 문구를 표시하지 못하면 결과를 완료 처리하지 않고 안전 문구를 기본값으로 노출한다.
- 완료 조건: 결과의 모든 추정 금액·운영 관련 정보에 비보장 및 확인 필요 안내가 노출된다.

### F-16. 결과 항목 직접 편집 및 다시 만들기

- 사용자 행동: 결과의 일자별 코스, 예산 항목·금액, 준비물, 우천 대안에서 `수정`을 선택해 내용을 고치고 저장·취소한다. 필요하면 `조건 재설정` 또는 `조건 다시 수정하기`를 선택해 전체 계획을 새로 만든다.
- 입력값: 사용자가 수정한 활동명·설명·시간, 예산 항목명·금액, 준비물·체크 상태, 우천 대안과 기존 생성 조건.
- 처리 규칙: 직접 편집은 현재 결과에 즉시 반영하고 `사용자 수정` 상태로 구분한다. 예산 금액을 편집하면 합계·1인 환산액·잔여 예산을 재계산하며, 음수 금액은 저장하지 않는다. 시간 편집은 같은 날짜 안에서 시간 순서를 검증한다. 전체 재생성은 기존 입력값을 입력 화면에 채워 두고 F-08 검증 후 F-09에서 수행하며, 새 결과로 교체하기 전 사용자에게 알린다. 가격·운영 관련 값은 실시간 정보로 보장하지 않는다.
- 출력값: 수정된 결과 영역, 사용자 수정 표시, 재계산된 예산 요약 또는 값이 유지된 입력 화면·새로 생성된 결과.
- 오류 상태: 필수 활동명·대안명이 비었거나 시간 순서·예산 금액이 유효하지 않으면 해당 편집란에 오류를 표시하고 저장하지 않는다. 기존 조건을 불러오지 못하면 빈 입력 화면과 “이전 조건을 불러오지 못했습니다. 다시 입력해주세요.”를 표시한다.
- 완료 조건: 사용자가 유효한 직접 편집을 저장하거나, 조건을 수정해 새 계획을 생성하거나, 취소로 기존 결과를 유지한다.

### F-17. 외부 지도에서 장소 확인

- 사용자 행동: 결과의 `지도에서 확인`을 선택한다.
- 입력값: 선택한 코스의 장소명과 여행지.
- 처리 규칙: 장소명으로 외부 지도 서비스의 검색 화면을 새 창 또는 새 탭으로 연다. 앱 안에서 지도를 표시하지 않고, 실시간 길찾기·현재 위치 추적·실시간 운영시간 보장은 제공하지 않는다.
- 출력값: 외부 지도 검색 화면으로 전달된 장소 검색어.
- 오류 상태: 외부 지도 열기에 실패하면 검색어를 복사 가능한 텍스트로 제공하고 “지도 서비스에서 직접 검색해주세요.”를 표시한다.
- 완료 조건: 사용자가 외부 지도에서 해당 장소를 확인할 수 있거나 검색어를 확보한다.

### F-18. 내 일정 보관

- 사용자 행동: `내 일정 보관`을 선택하거나 보관한 일정을 다시 연다.
- 입력값: 생성 조건, 결과 코스, 예산표, 체크리스트 상태, 우천 대안.
- 처리 규칙: 로그인 없이 현재 기기·브라우저의 로컬 저장소에 일정 데이터를 보관한다. 다른 기기·브라우저와 자동 동기화하지 않으며, 서버 계정 저장을 수행하지 않는다.
- 출력값: 보관 완료 안내, 보관한 일정 목록 또는 다시 연 결과.
- 오류 상태: 브라우저 저장소를 사용할 수 없거나 용량이 부족하면 “이 기기에서 일정을 보관할 수 없습니다.”를 표시하고 현재 화면의 결과는 유지한다.
- 완료 조건: 현재 기기에서 보관한 일정을 다시 열 수 있거나, 보관 실패 이유가 명확히 안내된다.

### F-19. 일정 공유

- 사용자 행동: `일정 공유`를 선택하고 기기의 공유 수단 또는 복사 기능을 선택한다.
- 입력값: 생성된 여행 요약, 일자별 코스, 예상 예산, 준비물, 우천 대안.
- 처리 규칙: 공유용 텍스트를 생성해 운영체제의 공유 창 또는 클립보드로 전달한다. 로그인, 계정 기반 수신자 관리, 서버에 저장되는 공개 공유 페이지는 제공하지 않는다. 추정 금액과 공식 채널 확인 필요 안내도 공유 내용에 포함한다.
- 출력값: 시스템 공유 창 또는 클립보드 복사 완료 안내.
- 오류 상태: 기기 공유 기능을 지원하지 않으면 “공유 기능을 사용할 수 없어 내용을 복사했습니다.”를 표시한다. 복사도 실패하면 공유용 텍스트를 화면에 표시한다.
- 완료 조건: 사용자가 일정 내용을 선택한 공유 수단으로 전달하거나 복사할 수 있다.

### F-20. 조건 충돌 오류 안내 및 해결 선택

- 사용자 행동: 예산·기간 등 조건 충돌 안내를 확인하고 자동 조정안, 일정 축소안, 또는 직접 수정을 선택한다.
- 입력값: 충돌한 여행 조건과 시스템이 계산한 추정 예산·기간 조정안.
- 처리 규칙: 입력 조건으로 실행 가능한 계획을 구성하기 어렵다고 판단되면, 그 이유와 조정안의 영향(예산 증액 또는 일정 축소)을 보여 준다. 제시 금액은 실시간 최소가나 보장 가격이 아닌 계획 생성을 위한 추정 기준임을 명시한다. 자동 조정을 선택하면 바뀌는 값만 적용해 F-09로, 직접 수정을 선택하면 F-16으로 이동한다.
- 출력값: 조건 충돌 설명, 1개 이상의 조정안, 자동 보정·직접 수정 행동 버튼.
- 오류 상태: 적절한 조정안을 만들지 못하면 직접 수정 버튼만 제공하고 F-21의 안내를 함께 표시한다.
- 완료 조건: 사용자가 조정안을 적용해 다시 생성하거나, 직접 수정 화면으로 이동한다.

### F-21. 계획 생성 실패 안내 및 재시도

- 사용자 행동: 생성 실패 안내에서 `다시 시도` 또는 `조건 수정`을 선택한다.
- 입력값: 마지막으로 검증된 여행 조건과 실패 유형(응답 지연, 생성 서비스 오류, 결과 데이터 불완전 등).
- 처리 규칙: 사용자가 입력한 조건을 유지한 채 실패 원인을 평이한 문구로 안내한다. 재시도는 F-09로, 조건 수정은 F-16으로 이동한다. 실패한 작업의 불완전한 예산·운영 정보는 결과로 노출하지 않는다.
- 출력값: 오류 설명, 다시 시도 버튼, 조건 수정 버튼.
- 오류 상태: 재시도도 실패하면 마지막 입력값을 보존한 동일 오류 화면을 유지하고, 반복 실패 사실을 안내한다.
- 완료 조건: 사용자가 재시도를 시작하거나 조건 수정으로 복구할 수 있다.
